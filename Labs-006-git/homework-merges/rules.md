# Правила сервісу бронювання

1. Місткість події: не більше 25 місць.
2. Скасувати бронювання може лише його власник не пізніше ніж за 48 годин до початку, групові бронювання — не пізніше ніж за 72 години; кошти при скасуванні повертаються автоматично.
3. Повторний запит з тим самим ключем не створює друге бронювання.
4. Якщо місць немає, користувач потрапляє в лист очікування.
5. Групою вважається бронювання від 5 осіб; група отримує знижку 10%.
